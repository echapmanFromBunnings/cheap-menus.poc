# cheap-menus.poc

## 🍦 The Gelato & Icecream Factory

A proof-of-concept static website showcasing a retro-styled ice cream parlor menu with vintage charm and nostalgic design.

### 🌐 Live Site

**View the live site here:** [https://echapmanfrombunnings.github.io/cheap-menus.poc/](https://echapmanfrombunnings.github.io/cheap-menus.poc/)

### 📖 Purpose

This repository demonstrates a simple GitHub Pages website for a fictional ice cream parlor called "The Gelato & Icecream Factory". The site features:

- **Retro Design**: Nostalgic color schemes and typography reminiscent of classic ice cream parlors
- **Interactive Menu**: Four distinct menu categories showcasing different flavor collections
- **Responsive Layout**: Grid-based design that adapts to different screen sizes
- **Visual Appeal**: Custom styling with gradients, shadows, and hover effects

### 📁 Repository Contents

- `index.md` - Welcome page and main navigation hub
- `1.md` - Classic Flavors menu (16 traditional favorites)
- `2.md` - Premium Selections menu
- `3.md` - Specialty Creations menu
- `4.md` - Ultimate Indulgences menu
- `_config.yml` - GitHub Pages configuration
- `logo.png` - Ice cream parlor logo

### 🛠️ Technology

Built using:
- **GitHub Pages** for hosting
- **Jekyll** for static site generation
- **Markdown** with embedded HTML/CSS for content and styling
- Retro-inspired design with custom CSS gradients and animations

### 🎨 Design Features

- Candy-striped background pattern
- Vintage color palette (pink, beige, and brown tones)
- Interactive hover effects on menu cards
- Responsive grid layouts
- Custom typography using monospace fonts
